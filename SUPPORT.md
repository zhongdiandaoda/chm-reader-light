# Support

Use these paths before opening a report:

- Installation and first launch: [macOS Install Guide](./docs/install-macos.md)
- Unsupported or unusual CHM behavior: [Compatibility](./docs/compatibility.md)
- Local files and saved state: [Privacy](./docs/privacy.md)
- Common errors: [Troubleshooting](./docs/troubleshooting.md)
- Security concerns: [Security Policy](./SECURITY.md)

For bugs, install help, compatibility reports, feature requests, performance issues, accessibility issues, or documentation problems, use the matching [GitHub issue form](https://github.com/zhongdiandaoda/chm-reader-light/issues/new/choose). Use [GitHub Discussions](https://github.com/zhongdiandaoda/chm-reader-light/discussions) for open-ended questions.

## Useful Report Details

- macOS version and Mac architecture
- CHM language and approximate size
- smallest repeatable steps
- expected and actual behavior
- **Help > Copy Diagnostic Info** output

Do not publish private CHM files, proprietary screenshots, document text, sensitive paths, or exploit details.
