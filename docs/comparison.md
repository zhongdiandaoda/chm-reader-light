# Comparison

Use this page when deciding whether CHMReaderLight is the right local-only macOS CHM reader for your documentation workflow.

CHMReaderLight is intentionally narrower than Windows HTML Help, browser-based extracted HTML folders, and general document managers. It focuses on a library-first macOS app for reading existing CHM files with safer defaults, searchable table of contents, body search, reading history, local metadata, and no hosted document storage.

## Choose CHMReaderLight When

- You want a local-only macOS CHM reader that opens downloaded or archived `.chm` manuals without copying source files into a managed database.
- You keep legacy SDK manuals, vendor help files, or offline API reference on disk and need grouping, library search, recently opened books, and Finder reveal actions.
- You want the reader to block CHM-authored scripts, forms, popups, plugin objects, nested frames, and network connections by default.
- You need a quick GitHub Releases download path for Apple Silicon or Intel Macs, plus checksum files for release artifacts.

## Choose Another Tool When

- You need Windows HTML Help compatibility exactly as it behaves on Windows.
- You want to edit, author, decompile, or rebuild CHM files; CHMReaderLight is not a CHM authoring tool.
- You prefer browser-based extracted HTML and already have a trusted extraction workflow for every manual.
- You need cross-device sync, hosted documentation, OCR, PDF libraries, annotation systems, or general document managers.
