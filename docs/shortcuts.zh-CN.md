# CHMReaderLight 中文快捷键指南

[English Keyboard Shortcuts](./shortcuts.md)

CHMReaderLight 遵循常见 macOS 快捷键，用于打开文件、查找、导航和缩放。应用内也可以从 **Help > Keyboard Shortcuts** 打开这份参考。键盘、辅助技术和外观预期见 [中文无障碍指南](./accessibility.zh-CN.md) 或 [Accessibility Guide](./accessibility.md)。

## 全局

| 快捷键 | 操作 |
| --- | --- |
| `Command+O` | 添加一个或多个 CHM 文件到当前书库分组。 |
| `Command+L` | 返回书库。 |
| `Command+F` | 聚焦当前视图的搜索框，可能是书库搜索或阅读器搜索。 |
| `Shift+Command+C` | 复制包含 release、star、反馈和 showcase 链接的项目分享文案。 |

## 阅读器

| 快捷键 | 操作 |
| --- | --- |
| `Command+[` | 在阅读历史中后退。 |
| `Command+]` | 在阅读历史中前进。 |
| `Command+Up` | 按 table-of-contents 顺序打开上一章。 |
| `Command+Down` | 按 table-of-contents 顺序打开下一章。 |
| `Command+B` | 显示或隐藏目录侧栏。 |
| `Command+G` | 跳到当前页面的下一个搜索匹配项。 |
| `Shift+Command+G` | 跳到当前页面的上一个搜索匹配项。 |
| `Command+-` | 缩小正文。 |
| `Command+=` 或 `Command++` | 放大正文。 |
| `Command+0` | 将正文缩放重置为 100%。 |

## 菜单和对话框

| 快捷键 | 操作 |
| --- | --- |
| Search scope menu: `ArrowUp` / `ArrowDown` | 在 Body 和 Directory 搜索范围之间移动焦点。 |
| Search scope menu: `Enter` 或 `Space` | 选择当前聚焦的搜索范围选项。 |
| `Escape` | 关闭已打开的 popover menu 或书库分组对话框。 |

当焦点在 input、textarea、select 或可编辑区域中时，和文本编辑冲突的快捷键会被忽略。
