# CHMReaderLight 中文 Showcase 指南

[English Showcase Guide](./showcase.md)

当用户想分享 CHMReaderLight 如何改善自己的离线 CHM 工作流时，可以使用这份指南。目标是收集未来访问者可以信任的真实案例，同时不虚构推荐语，也不暴露私有文档。

## 可以分享什么

- 离线 CHM 工作流，例如在 macOS 上管理旧版 SDK 手册、厂商帮助文件或归档 API 文档。
- 使用 CHMReaderLight 后发生了什么变化，例如重新打开更快、书库搜索更容易、本地优先阅读更安心，或兼容性报告更清楚。
- 最有帮助的功能：书库分组、可搜索目录、正文搜索、阅读历史、Finder 操作、诊断信息或 release 打包。
- 安全上下文，例如 macOS 版本、Mac 架构、安装来源、CHM 语言和大致书库规模。

## 隐私规则

- 不要包含私有文档内容、专有截图、敏感文件路径、客户名称、内部产品名或保密 CHM 文本。
- 公开发布前，请先脱敏截图和复制出的诊断信息。
- 在 README、release notes 或分享材料里复用故事前，先确认引用许可。
- 如果报告者不希望署名，请使用匿名表述。

## 维护者如何复用故事

- 当某个故事能帮助首次访问者理解真实工作流时，可以从 README 链接到它。
- 如果某次改动直接改善了报告中的工作流，可以在 release notes 中引用简短且已获许可的亮点。
- 多个故事反复出现同一使用场景时，更新 [中文分享素材包](./share-kit.zh-CN.md) 或 [Share Kit](./share-kit.md) 的受众措辞。
- 只陈述报告者实际描述的内容，不要把单个故事扩展成广泛兼容性承诺。
