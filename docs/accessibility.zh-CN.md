# CHMReaderLight 中文无障碍指南

[English Accessibility Guide](./accessibility.md)

本指南汇总 CHMReaderLight 当前的键盘、辅助技术和外观预期，帮助用户在采用前判断应用是否适合自己的阅读方式。

## 当前支持

- 通过原生 macOS 菜单和已记录的快捷键支持键盘优先的书库和阅读器工作流。
- 可见焦点状态帮助用户跟踪键盘在书库卡片、工具栏控件、对话框和菜单之间的移动。
- 书库数量、搜索无结果、章节进度和复制操作等状态变化会使用 polite announcements。
- 阅读器缩放和文本编码偏好会在两次启动之间保留，让重复阅读 CHM 更舒适。

## 已知限制

- CHMReaderLight 当前使用浅色外观。
- 还没有深色模式或高对比主题开关。
- VoiceOver 覆盖会通过真实报告继续改进，而不是做宽泛承诺。
- CHM 自带内容差异很大，部分提取页面可能继承原始帮助文件 markup 中的无障碍问题。

## 报告无障碍缺口

当键盘导航、焦点顺序、VoiceOver 输出、颜色对比或外观行为让 CHM 阅读变困难时，请使用 accessibility issue template。

请包含：

- 受影响的工作流，例如书库管理、阅读器导航、搜索或某个工具栏控件。
- 你使用的输入方式或辅助技术。
- macOS 外观设置。
- 最小复现步骤。
- 期望的可访问行为。
- **Help > Copy Diagnostic Info** 输出。
- 如果有助于说明问题，可以附上安全的截图或录屏。

不要在公开报告中包含私有 CHM 内容、敏感文件路径或保密截图。
