# CHMReaderLight 中文演示指南

[English Demo Guide](./demo-guide.md)

录制 README 视频、release note 片段或 GitHub social preview walkthrough 时，可以使用这份指南。目标是快速展示真实的 CHMReaderLight 书库到阅读器工作流，同时不暴露私有文档内容。选择公开或合成文件前，请先看 [中文 CHM 样本指南](./sample-chm-guide.zh-CN.md)；准备发布文案时，可以配合 [中文分享素材包](./share-kit.zh-CN.md)。

## 60 秒流程

- 从书库视图开始，准备一到两个安全的示例 CHM 文件。
- 拖拽一个或多个 `.chm` 文件到书库窗口，展示应用会保留原始源文件位置。
- 在平铺和列表布局之间切换，再按书名或源路径过滤书库。
- 打开一本书，并过滤可搜索目录。
- 执行正文搜索，在匹配之间跳转，并复制当前章节引用。
- 调整缩放或文本编码，展示阅读偏好可以在不离开文档的情况下修改。
- 如果演示用于项目分享，结尾使用 **Help > Star on GitHub**。

## 录制检查清单

- 使用可丢弃 CHM 文件、合成 CHM，或可以公开展示的公共手册。
- 不要展示私有文档内容、私有文件路径、内部产品名或未发布客户材料。
- 保持应用窗口足够大，让书库侧栏、书籍列表、目录和阅读器工具栏都清晰可见。
- 优先录制一段连续短视频，而不是多个互不连贯的片段。
- 如果演示附在 release 中，请说明构件是 Apple Silicon 还是 Intel，以及来自 GitHub Releases 还是本地打包。
- 发布公开 walkthrough 前，重新检查 [中文隐私与本地数据](./privacy.zh-CN.md)、[中文安全模型](./security-model.zh-CN.md) 和 [中文兼容性说明](./compatibility.zh-CN.md)。
