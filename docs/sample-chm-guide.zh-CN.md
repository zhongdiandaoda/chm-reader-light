# CHMReaderLight 中文 CHM 样本指南

[English Sample CHM Guide](./sample-chm-guide.md)

选择用于截图、短演示、兼容性报告或贡献 fixture 的 CHM 文件时，请优先使用本指南。好的样本能让其他人快速评估 CHMReaderLight，同时避免暴露私有文档。

## 使用公开或合成样本

- 如果许可证允许重新分发或公开截图，可以使用公开样本 CHM。
- 如果只是复现目录嵌套、文本编码、内部链接、图片路径或搜索行为，请构建一个小型合成 CHM。
- 样本名称、文件夹名称和页面内容应保持通用，方便在公开 issue、日志或截图中展示。
- 不要提交私有 CHM 文件、提取后的专有文档、客户手册、内部 SDK，或会泄露保密文本的截图。

## 好的演示材料

优先选择能展示下列至少两类工作流的样本：

- 带有嵌套目录的 table of contents。
- 可以用可见词语或类似 API 符号触发的正文搜索。
- 能证明资源解析正常的图片或内部链接。
- 多个页面，方便展示上一章和下一章导航。
- 可以公开展示，或能安全移除本地路径的文件位置。

## 安全分享

- 发布日志、截图或复制出的诊断信息前，始终移除本地路径。
- 尽量避免包含专有内容的截图，也不要展示私有文件名、个人目录或内部产品名。
- 在公开 issue 中，优先使用最小复现 CHM，而不是大型真实手册。
- 如果只有私有文件能复现，请描述受影响区域，并说明可以私下协调，不要直接上传文件。

## 适用场景

- 按 [中文演示指南](./demo-guide.zh-CN.md) 或 [Demo Guide](./demo-guide.md) 录制公开演示或 README walkthrough。
- 按 [中文兼容性说明](./compatibility.zh-CN.md) 提交足够聚焦、可复现的兼容性报告。
- 为解析、搜索、编码、内部链接或图片路径工作准备小型测试 fixture。
- 准备贡献截图，同时不泄露私有文档内容。
