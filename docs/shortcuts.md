# Keyboard Shortcuts

CHMReaderLight follows common macOS shortcuts for opening, finding, navigation, and zooming. This page is also available from **Help > Keyboard Shortcuts** in the app. See [Accessibility Guide](./accessibility.md) for current keyboard, assistive technology, and appearance expectations.

## Global

| Shortcut | Action |
| --- | --- |
| `Command+O` | Add one or more CHM files to the current library collection. |
| `Command+L` | Return to the library. |
| `Command+F` | Focus the active search field in the library or reader. |
| `Shift+Command+C` | Copy reusable project share text with release, star, feedback, and showcase links. |

## Reader

| Shortcut | Action |
| --- | --- |
| `Command+[` | Go back in reading history. |
| `Command+]` | Go forward in reading history. |
| `Command+Up` | Open the previous topic in table-of-contents order. |
| `Command+Down` | Open the next topic in table-of-contents order. |
| `Command+B` | Show or hide the table-of-contents sidebar. |
| `Command+G` | Move to the next search match on the current page. |
| `Shift+Command+G` | Move to the previous search match on the current page. |
| `Command+-` | Decrease reader zoom. |
| `Command+=` or `Command++` | Increase reader zoom. |
| `Command+0` | Reset reader zoom to 100%. |

## Menus and Dialogs

| Shortcut | Action |
| --- | --- |
| Search scope menu: `ArrowUp` / `ArrowDown` | Move between Body and Directory search scope options. |
| Search scope menu: `Enter` or `Space` | Select the focused search scope option. |
| `Escape` | Close open popover menus or the collection dialog. |

Shortcuts that would conflict with text editing are ignored while an input, textarea, select, or editable region is focused.
